# Phase 7 — Free launch 1.0 (3 weeks, ends 2027-04-18)

Spec: §10 Phase 7 + Free launch and marketing plan; §9 Distribution.
Goal: public, free downloads on 3 OSes with a launch that reaches the target audience.

## Product

- [ ] **P7-01** Release candidate: freeze features, fix P0 bugs only, version `1.0.0-rc.1` on beta channel for one week. · model: sonnet
- [ ] **P7-02** Stable channel manifest, release notes, archive of all builds (kept forever per §8 fallback promise). · model: sonnet
- [ ] **P7-03** Package managers: Homebrew cask, winget manifest, AUR PKGBUILD, Flathub submission; verify install/uninstall/update paths. · model: sonnet
- [ ] **P7-04** Support: `support@` inbox, status page, public issue tracker template, Discord channels reorganised for public. · model: sonnet

## Site and content

- [ ] **P7-05** Landing page: downloads per OS with auto-detect, feature tour with 6 short videos (line staging, log, rebase, merge, PR review, GitLab), FAQ, newsletter, privacy policy, terms of use (free, no warranty). · model: sonnet
- [ ] **P7-06** Comparison pages: vs GitHub Desktop, Fork, Sublime Merge, GitKraken, Tower, IntelliJ (honest, feature tables from Appendix A). · model: sonnet
- [ ] **P7-07** Docs site: getting started, every view, keyboard reference, GitHub/GitLab setup incl. self-hosted, troubleshooting (credentials, Windows long paths, macOS Git), changelog. · model: sonnet
- [ ] **P7-08** Launch blog post: "Line-level staging explained" + the story of why this exists; second post "Interactive rebase without fear". · model: sonnet
- [ ] **P7-09** Press kit: logo, screenshots per OS, one-paragraph description, founder bio. · model: sonnet

## Launch sequence

- [ ] **P7-10** Day −7: email waitlist with date; tease on social. · model: sonnet
- [ ] **P7-11** Day 0: Show HN (morning US Pacific), Product Hunt, r/git + r/programming, dev.to post, Lobsters; founder answers every comment for 48 h. · model: sonnet
- [ ] **P7-12** Day +1..+7: newsletters (TLDR, Bytes, Console) submissions; JetBrains/VS Code subreddits; GitLab forum; YouTube demos. · model: sonnet
- [ ] **P7-13** Metrics dashboard: downloads per OS, weekly active (opt-in), newsletter growth, issues opened/closed, Discord members, share of users connecting an account. · model: sonnet

## Exit criteria

- Public downloads on macOS, Windows, Linux; package-manager installs verified.
- Launch-week metrics captured against §1 targets (5,000 installs / 1,000 WAU / 3,000 subscribers at 90 days).
- Support and feedback loops live; top launch issues triaged within 72 h.
